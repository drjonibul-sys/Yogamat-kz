# Журнал изменений — PWA «Yogamat.kz — студия»

Правило версий X.Y.Z: X — значительное изменение, Y — незначительное, Z — оптимизации/исправления. Версия и «Разработано Yogamat.kz» показываются на каждой вкладке.

## 1.2.0 — 2026-11-18
- Выгрузка в PDF (A4, книжная ориентация): кнопка «PDF» на странице «Клиенты», «Скачать табель (PDF, A4)» в настройках, «PDF» в разделе «Долги». CSV остаются.
- PDF строится на устройстве (jsPDF + AutoTable в `docs/vendor/`, шрифт DejaVu Sans с кириллицей и ₸), без интернета после первой загрузки. Колонтитул: версия, «Разработано Yogamat.kz», «Стр. N из M»; пустые колонки не печатаются, шапка таблицы повторяется на каждой странице.
- После создания открывается окно «PDF готов»: «Сохранить или отправить» (на iPhone/iPad — меню «Сохранить в Файлы»), «Открыть для просмотра».
- Тест `pwa-tests/browser/e2e3.py`: формат 595×842 pt, несколько страниц, кириллица, кнопки.

## 1.1.2 — 2026-11-18
- Верхний пояс (кнопка «Назад» и название) закреплён при прокрутке на всех внутренних страницах: список комплексов, комплекс, справочник асан, карточка асаны и др. Учитывается вырез/статус-бар iPhone.

## 1.1.1 — 2026-11-18
- Возврат кнопкой «Назад» восстанавливает позицию прокрутки страницы (список комплексов, комплекс, справочник и др.). Новые страницы открываются сверху, автоматической прокрутки нет.

## 1.1.0 — 2026-11-18
- Оформление: «Светлая», «Тёмная», «Как в системе» (Настройки → Оформление); выбор сохраняется, применяется без вспышки при запуске.
- Телефоны: при фокусе в поле подставляется «+7 », ввод форматируется в «+7 701 234 56 78», «8…» заменяется на «+7».
- Версии: сравнение по числам (1.10.0 новее 1.9.0) с файлом `version.json` на сайте; одинаковая версия больше не считается обновлением; на Обзоре появляется карточка «Доступна версия X». Файл `version.json` не кэшируется service worker. При каждом выпуске менять версию в `store.js`, `sw.js` и `version.json` (проверяет тест).
- Комплексы: возврат из асаны ведёт в тот комплекс, откуда её открыли (кнопка «Назад» теперь возвращает на предыдущую страницу; при прямой ссылке — в справочник).
- Комплексы: порядок кнопок и разделов — Лёгкая, Лёгкая → средняя, Средняя, Средняя → тяжёлая, Тяжёлая.
- Тесты: 26 логики, 18 + 26 в браузере.

## 1.0.0 — 2026-11-18
PWA создано по образцу нативного приложения (SwiftUI), папка `docs/`.
- Вход по PIN, роли «Администратор» и «Тренер», код восстановления, блокировка на 30 с после 5 неверных попыток; PIN хранится как солёный хэш SHA-256.
- Вкладки: Обзор, Клиенты, Визиты, Доход (только админ), Классы. Настройки и аккаунт открываются с Обзора.
- Клиенты, абонементы (оплата с датой, перенос срока), быстрая продажа, отметка визитов, отмена записи (занятие возвращается).
- Расписание: 16 направлений по умолчанию, неделя/месяц, запись на занятие с проверкой мест, постоянная запись на 1–12 недель, редактор направлений.
- Доход: поступления, аренда, итог, диаграмма по месяцам, платежи, долги, тарифы, аренда студии, загрузка направлений и тренеров.
- Данные: хранятся в браузере устройства; резервные копии (25 шт., раз в неделю автоматически), экспорт/импорт JSON, CSV клиентов, визитов, долгов.
- Справочник 200 асан (WebP) и 15 практик, избранное.
- Офлайн через service worker; публикация через GitHub Actions → GitHub Pages.
- Тесты: `node pwa-tests/store.test.js` (23), `python3 pwa-tests/browser/e2e.py` (26).
- Не перенесено из нативного: напоминания (уведомления), PDF (вместо них CSV), Keychain.
- Заметки по багам прошлых приложений проекта учтены: подписи форм без confirm(), тестирование офлайна, версия кэша = версия приложения.
