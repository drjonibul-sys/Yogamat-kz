## 1.6.0 — 2026-11-18
Тип: Y (новая возможность; отмена прежней)
- Добавлено: восстановление PIN по контрольному вопросу (перенесено из ранее разработанного приложения, `team.js`, версия 1.1.0–1.4.0 той ветки). У каждого пользователя (администратор и тренеры) свой вопрос и ответ. 5 типовых вопросов + «Свой вопрос» (до 80 знаков). Ответ нормализуется (регистр, пробелы, знаки, е/ё не важны), минимум 3 знака, хранится только как солёный хэш в хранилище PIN — в резервные копии и JSON-экспорт не попадает.
- Первый запуск: вопрос и ответ обязательны для администратора (без кода восстановления это единственный способ вернуть доступ).
- «Забыли PIN?»: при заданном вопросе показывается вопрос → ответ → новый PIN → вход. Лимит попыток общий с входом: 5 неверных — пауза 30 с. Если вопрос не задан: тренеру — «обратитесь к администратору» (он задаёт новый PIN в карточке тренера), у администратора — сообщение, что восстановить нельзя.
- Аккаунт (значок с буквой на Обзоре) → «Контрольный вопрос»: задать, изменить, удалить (нужен свой PIN; перед удалением предупреждение). В списке тренеров у администратора отмечено «есть контрольный вопрос». На Обзоре у пользователя без вопроса показывается напоминание.
- Отменено: «защитная комбинация» — код восстановления XXXX-XXXX (экран с кодом при первом запуске, «Скопировать код», восстановление по коду, `makeRecoveryCode`, `resetPIN`). Ранее сохранённый код автоматически удаляется из хранилища при запуске.
- ВАЖНО для действующих установок: у уже созданного администратора вопроса нет — задайте его сразу (напоминание на Обзоре). Пока вопрос не задан, забытый PIN администратора восстановить нельзя; рекомендуется регулярно сохранять базу в файл JSON.
- guide.js ред. 1.6.0 (FAQ: «Что делать, если забыл PIN?», обновлены вопросы о входе и аккаунтах).
- Тесты: store.test.js (34), e2e7.py (настройка, восстановление, удаление вопроса), e2e*.py обновлены под новый первый запуск; тест закреплённого пояса асаны стабилизирован.

## 1.4.0 — 2026-11-18
Тип: Y (новые возможности)
- Администратор может менять название студии и логотип (Настройки → «Название студии» / «Выбрать логотип» / «Вернуть стандартный»). - ПРАВИЛО: при изменении экранов/алгоритмов обновлять `docs/guide.js` (поднять `GUIDE_REV`) и отмечать это в журнале.
