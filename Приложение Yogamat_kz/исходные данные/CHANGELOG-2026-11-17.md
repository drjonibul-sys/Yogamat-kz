# Изменения 17.11.2026 (проверка и адаптация для iPad Pro 10,5, iPadOS 17)

1. **Переполнение localStorage (~5 МБ).** `saveState()` при ошибке записи удаляет самые старые резервные копии и повторяет запись; если места всё равно нет — показывает предупреждение «последнее изменение НЕ сохранено» вместо молчаливой потери.
2. **Бюджет резервных копий.** Копии ограничены по числу (25) и суммарному размеру (~1,2 млн символов), чтобы не вытеснять рабочие данные. Автокопия при нехватке места не ломает приложение, а показывает уведомление.
3. **Подпись копии «перед обновлением»** (`pre-update`) вместо технического кода.
4. **Зум при фокусе на поле «Примечание»** (шрифт 12 px → 16 px) в таблице «Визиты».
5. **Обновление приложения не перекачивает иллюстрации.** `build-pwa.py` пишет хэш каждого файла; новый Service Worker при установке копирует неизменённые изображения из кэша прежней версии. Первое обновление со старого SW всё равно скачает файлы целиком. Тест добавлен в `tests/pwa-check.cjs`.
6. **Повреждённые данные не затираются молча.** Нечитаемая запись сохраняется в `yogaTrackerCorrupt_v1`, показывается одно предупреждение.
7. **Портретная ориентация iPad (834 px).** Таблица «Визиты» помещается без горизонтальной прокрутки (меньшие отступы, колонка «Примечание» 130 px).
8. **Документация:** iPadOS 16 → 17, «шесть» → «семь» наборов тестов.

По замыслу: клиент исчезает из сетки «Визиты» после последнего визита — не менять.
Не проверено в этой среде: настоящий Safari 17, установка на экран «Домой», печать в PDF — проверить на устройстве по чек-листу из REVIEW.
