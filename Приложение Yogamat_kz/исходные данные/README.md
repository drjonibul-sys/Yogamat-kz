# Йога-практика — браузерная версия (PWA)

Сохранены структура и пастельный дизайн. Приложение ведёт учёт клиентов, абонементов, визитов и ежемесячной аренды, считает доход после оплаченной аренды в тенге, поддерживает JSON-копии, PDF через печать и справочник 200 асан и вариантов с анатомическими иллюстрациями девушки. Xcode и установка IPA не нужны.

## На iPhone и iPad

1. Откройте размещённое приложение по HTTPS-ссылке в **Safari или Firefox**. Если включён вход по e-mail, введите адрес, выданный администратором, и код из письма (см. `docs/EMAIL-AUTH.md`). Публикация и обновление на бесплатном хостинге: `docs/HOSTING.md`.
2. На вкладке **Обзор** дождитесь надписи **«Готово к работе без интернета»**. Это означает, что интерфейс, шрифты, справочник и все иллюстрации сохранены.
3. Выберите **Поделиться → На экран «Домой» → Добавить**. В некоторых версиях iOS есть переключатель **«Открывать как веб-приложение»** — включите его.
4. Запускайте **Йога-практику** с появившегося значка. После установки ещё раз откройте приложение с интернетом и проверьте готовность автономной копии именно в этом окне.

Статус «Приложение с домашнего экрана» означает способ запуска; он не зависит от наличия сети. Для iPad Pro 10,5 с iPadOS 16 установка поддерживается. Если старый значок открывает Safari, сначала сохраните JSON-копию и создайте новый значок из актуальной страницы в Safari.

Если ссылка открыта внутри другого приложения, сначала выберите «Открыть в Safari». Инструкция также доступна через значок со стрелкой в шапке и кнопку «На главный экран» в обзоре.

В Chrome на Android/компьютере можно использовать «Установить приложение» в меню браузера; когда браузер предоставляет системный диалог, кнопка установки доступна и внутри приложения.

При загрузке показывается количество сохранённых файлов. Сначала становится доступен учёт и текстовый справочник, затем изображения скачиваются по две одновременно. При обрыве нажмите «Повторить загрузку»: уже сохранённые файлы повторно не скачиваются. Полная готовность подтверждается только после проверки всего списка.

Проверка на iPad: дождитесь готовности в окне со значка, включите авиарежим и выключите Wi-Fi, закройте приложение и заново откройте значок. Учёт и изображения должны открываться без сети. Не удаляйте данные Safari для обновления — это может удалить ваши записи.

## Данные и перенос

Записи хранятся в localStorage браузера на конкретном устройстве. Облачной синхронизации и отправки данных клиентов на сервер нет. Установленное веб-приложение и обычная вкладка Safari могут иметь отдельные хранилища. Перенос выполняется через шестерёнку: экспорт JSON → открыть приложение со значка → импорт того же JSON. Так же переносятся записи из прежнего HTML или нативной версии.

Раз в неделю при открытии/возвращении создаётся внутренняя копия; сохраняются последние 25. Перед восстановлением создаётся копия текущего состояния. Внутренние копии находятся в том же браузерном хранилище: регулярно экспортируйте JSON отдельно в «Файлы». Очистка данных сайта или вытеснение данных браузером может удалить записи и офлайн-копию. Приватный режим не подходит для постоянного учёта.

Обновление приложения предлагается отдельной кнопкой. Оно не очищает данные клиентов. Для доступа к внешним источникам асан, первичного входа на частный сайт и загрузки обновлений требуется интернет. Без сети работают уже сохранённые интерфейс, учёт, локальные копии и справочник. Недельное фоновое задание при закрытом приложении не запускается.

PDF: **Визиты → Экспорт визитов за месяц в PDF**. На iPhone/iPad в системном окне печати откройте предпросмотр разведением двух пальцев, затем **Поделиться → Сохранить в Файлы**. Экспорт JSON использует системный общий доступ, если он поддерживается, иначе загрузку файла.

## Размещение на своём хостинге

Содержимое `dist/` — готовый статический сайт. Загрузите **все** файлы из этой папки на статический HTTPS-хостинг, сохранив структуру каталогов. Подходит корень домена или отдельная папка: пути manifest, Service Worker и ресурсов относительные. Открытие `index.html` из приложения «Файлы» не обеспечивает установку PWA или офлайн-кэш.

Рекомендуемые HTTP-заголовки: `sw.js`, `index.html` и `manifest.webmanifest` — `Cache-Control: no-cache`; для manifest — `Content-Type: application/manifest+json`, для JS — `text/javascript`. Service Worker должен загружаться без перенаправления и в пределах папки приложения. Проверка кэша отвергает ошибочные страницы входа вместо иллюстраций/скриптов.

При изменении ресурсов запустите `python3 build-pwa.py`: команда пересчитает версию и полный список автономных файлов. Затем повторно загрузите `dist/`. Анатомические иллюстрации 200 позиций находятся внутри в 35 наборах и доступны без сети; лицензии шрифтов включены. Происхождение иллюстраций — `docs/IMAGE-CREDITS.md` и подписи в карточках.

## Проверки

`node tests/pwa-check.cjs` проверяет manifest, иконки, все локальные ресурсы, бизнес-правила дат/переносов/посещений и Service Worker в изолированной Node VM: автономные ответы, целостность кэша, ошибки входа, безопасные обновления. Отчёт — `tests/results.json`.

Новая браузерная версия не проверялась в живом браузере или на физических iPhone/iPad в этой среде: инструмент браузерного QA Sites недоступен. Проверки Node не подтверждают системную установку Safari, экранную клавиатуру или печать PDF на iOS. Исходный интерфейс ранее проходил браузерные проверки, но это не заменяет проверку установки текущей PWA на устройстве.

## Анатомические иллюстрации

Изображения созданы для приложения в стиле проекта «ФОРМА — домашние тренировки», адаптированном к йоге: взрослая женская фигура, светлый фон, шалфейные, пудрово-розовые и мягкие терракотовые оттенки. Подсветка мышц условная; это иллюстрации положений тела, а не индивидуальная карта нагрузки. Техника и источники справочника сохранены.

## Фактический доход и уровни справочника

Поступления рассчитываются только по абонементам с `paid === true` и корректной датой `paidDate`, по месяцу оплаты. Из них вычитается только оплаченная аренда соответствующего месяца аренды. Шапка, годовая сумма, оба графика и накопительная таблица используют единый расчёт дохода после аренды и поддерживают отрицательный результат. Выключение отметки оплаты отменяет соответствующее поступление или расход. Для просмотра истории есть выбор месяца и года. Старые записи без отметки оплаты остаются неоплаченными; дата оплаты не придумывается.

Справочник содержит ровно 200 позиций: 80 — «Лёгкий», 70 — «Средний», 50 — «Тяжёлый». Названия, техника, нюансы, опоры, ограничения и анатомические иллюстрации доступны офлайн. Уровни обозначают ориентировочную физическую сложность; подготовка и индивидуальные ограничения важнее группы.

Дополнительные проверки: `node tests/income-check.cjs`, `node tests/catalog-check.cjs`, `node tests/pwa-ui-check.cjs` (индикация запуска, прогресс, повтор загрузки).

## Учёт аренды

Раздел «Аренда» сохраняет сумму для автоматического заполнения текущего и шести следующих месяцев, историю платежей и общую выплаченную аренду. При смене месяца окно автоматически продлевается ещё на месяц. До отметки «оплачено» на главной странице видны напоминания; сумма не вычитается из дохода. Настройки и платежи входят в JSON-копии, старые копии без аренды совместимы. Подробнее: [руководство по аренде](docs/RENT.md). Регрессионные проверки: `node tests/rent-check.cjs`.

## Примеры проведения практик

В «Справке» появилась вкладка «Практики»: 15 комплексов длительностью 45–75 минут. Для лёгкого, среднего и тяжёлого уровней предусмотрено по 3 основных комплекса; ещё по 3 готовят к переходам между соседними уровнями. Практики разделены на пять самостоятельных групп по порядку: переход с лёгкого на средний → переход со среднего на тяжёлый → лёгкая → средняя → тяжёлая. В каждой группе по 3 комплекса. Кнопки фильтров расположены отдельно: «Все», «Лёгкая», «Лёгкая → средняя», «Средняя», «Средняя → тяжёлая», «Тяжёлая». В общем списке первыми показаны переходные комплексы.

В карточке — задача, подходящая подготовка, оборудование, основные ориентиры и поминутный план. Каждый этап включает технику, ориентиры по ощущениям, упрощение и ссылки на карточки асан. Время включает обе стороны, входы, выходы и отдых. Сложные элементы выполняются короткими подходами, а не всё время блока; указаны замены. Из карточки асаны можно вернуться к исходной практике с восстановлением положения прокрутки. Планы и оформление включены в автономную копию.

Данные: `content/practices.json`, браузерный набор: `dist/practices.js`. `node tests/practices-check.cjs` проверяет распределение 3 + 3 + 3 основных и 3 + 3 переходных, суммы времени, ссылки на существующие асаны и навигацию в Node VM. Это не проверка на физическом iPad и не индивидуальная оценка нагрузки.
