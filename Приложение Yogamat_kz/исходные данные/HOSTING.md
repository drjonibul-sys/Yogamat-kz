# Публикация на бесплатном хостинге

Приложение статическое: достаточно раздать содержимое папки `dist/` по HTTPS. Подходят Cloudflare Pages, GitHub Pages, Netlify (бесплатные планы).

## Первая публикация
1. (Если нужен вход по e-mail) заполните `dist/auth-config.js` (см. `EMAIL-AUTH.md`).
2. Выполните `python3 build-pwa.py`: пересчитывает `sw.js` и `app-update.json`. Запускать после любого изменения файлов в `dist/`.
3. Загрузите содержимое `dist/` на хостинг (корень сайта или подпапка).
4. Откройте адрес сайта на iPhone/iPad в Safari или Firefox → Поделиться → «На экран Домой».

## Адрес сайта для обновлений
При первом открытии через HTTPS адрес запоминается автоматически (Настройки → «Обновления приложения» → «Адрес сайта-источника»). Если сайт переехал или адрес нужно задать вручную, впишите его там и нажмите «Сохранить адрес»; «Вернуть текущий сайт» подставит адрес открытой страницы.

## Обновление
1. Внесите изменения, поднимите версию (`APP_VERSION` в `index.html` по правилу X.Y.Z), выполните `python3 build-pwa.py`.
2. Загрузите `dist/` на хостинг поверх прежней версии.
3. На устройствах: Настройки → «Проверить обновления» → «Установить обновление» (также проверка идёт автоматически раз в 6 часов). Данные клиентов при этом не затрагиваются.

## Ограничения
- Установленное приложение и вкладка браузера имеют разные хранилища: данные не переносятся сами. Переносите через экспорт/импорт JSON.
- Бесплатные планы хостинга и Supabase имеют лимиты (письма, трафик, пауза неактивного проекта Supabase Free через неделю неактивности: сервер «просыпается» при первом запросе).
