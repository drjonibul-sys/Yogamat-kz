# Автономная работа на iPad Pro 10,5 (iPadOS 17)

Исправлена постоянная надпись «Приложение в браузере». Способ запуска определяется через `navigator.standalone` и `display-mode: standalone`; готовность автономной копии отображается отдельно. Работа без интернета не требует переключателя: Service Worker обслуживает сохранённые файлы и при наличии сети.

На опубликованном сайте подтверждено: `/index.html` отвечает HTTP 307 с перенаправлением на `/`, а `/` отдаёт корректный HTML приложения с HTTP 200. Прежний код запрашивал `index.html` с `redirect: error`, что отменяло установку. Теперь документ сохраняется напрямую по URL папки (корню области Service Worker), а старые адреса `index.html` тоже обслуживаются из сохранённой страницы. Проверка маркера HTML, отказ от страниц входа и сторонних перенаправлений сохранены.

Прежний Service Worker ждал скачивания всех иллюстраций одновременно ещё при установке. Ошибка любого большого файла отменяла всю установку. Теперь установка сохраняет сначала небольшой интерфейс, локальные шрифты и тексты справочника. После активации приложение запрашивает загрузку изображений по две одновременно. Обрыв не удаляет удачно сохранённые файлы; повтор докачивает недостающие. Статус содержит число файлов и различает готовность интерфейса и всей копии. Проверка использует ключи кэша без одновременного клонирования больших изображений. Отдельно обрабатываются нехватка места, ошибки установки и повтор регистрации. Удалённый браузером файл снова сохраняется при успешном сетевом открытии.

Новый Service Worker не переключается автоматически поверх открытой формы: пользователь нажимает «Обновить», после чего происходит перезагрузка. Записи localStorage и резервные копии не изменяются. Ошибочные ответы входа, перенаправления, внешние ресурсы и пользовательские данные не попадают в автономный кэш.

## Обновление и проверка на планшете

1. Сохраните JSON-копию записей через настройки.
2. С интернетом откройте приложение со значка и на «Обзоре» нажмите «Обновить», когда кнопка появится. Если обновление ещё не найдено, вернитесь в приложение при включённой сети — проверка запускается при возвращении.
3. Дождитесь «Готово к работе без интернета» именно в окне со значка. Если загрузка прервалась, нажмите «Повторить загрузку».
4. Включите авиарежим, выключите Wi-Fi, закройте приложение и запустите его со значка. Проверьте учёт и несколько изображений асан.
5. Если фактический статус всё ещё «Открыто во вкладке браузера», старый значок является закладкой. Сохраните JSON и создайте новый через Safari → «Поделиться» → «На экран Домой». Импортируйте JSON при необходимости: Safari и установленное приложение могут иметь разные хранилища.

Не очищайте данные сайта для обновления. При вытеснении офлайн-файлов браузером их потребуется скачать снова. Вход при первом открытии и внешние источники требуют интернета.

## Проверки

Node VM проверяет загрузку основного интерфейса, прерывание и возобновление иллюстраций, максимум двух запросов, прогресс, защиту от HTML-страницы входа, восстановление вытесненных файлов и автономные ответы. Отдельные DOM-заглушки проверяют надписи для ярлыка и вкладки, действия при ошибках и прогресс. Browser QA Sites недоступен в этой среде (нет cua_repl.js); физический iPad с iPadOS 17 не тестировался. Эти проверки не заменяют описанную проверку на планшете.
