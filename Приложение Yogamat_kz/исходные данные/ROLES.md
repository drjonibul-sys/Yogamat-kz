# Роли: администратор и тренеры

При первом запуске приложение просит задать PIN администратора (4–8 цифр) и показывает код восстановления (один раз). Дальше при открытии приложения выбирается пользователь; выбранная роль сохраняется на устройстве до команды «Сменить пользователя» (Настройки).

| | Администратор | Тренер |
|---|---|---|
| Клиенты: карточка, телефон, заметки, дата «клиент с» | редактирует, удаляет | только просмотр |
| Абонементы: даты, занятия, цена, оплата | редактирует, удаляет | видит остаток и срок, без цен и оплат |
| Посещения: отметка, дата, направление, отмена | да | да |
| Переносы: добавить, изменить, удалить | да | да |
| Примечание в таблице «Визиты» | да | да |
| Направления / классы | создаёт, редактирует, удаляет | только просмотр |
| Тарифы, продажи, доход, аренда | да | скрыто и заблокировано |
| Настройки: пользователи, PIN, резервные копии | да | только выход и установка на экран «Домой» |

Тренеров добавляет администратор: Настройки → Пользователи и роли (имя, PIN, отключение, удаление). Тренера можно назначить на направление.

Защита от подбора: после 5 неверных PIN вход блокируется на 30 секунд. Забытый PIN администратора сбрасывается по коду восстановления; новый код создаётся в Настройках.

Ограничение: это разграничение интерфейса на одном устройстве. PIN хранятся как солёные хэши, но данные приложения в памяти браузера не шифруются. Записи пользователей не попадают в резервные копии и экспорт; после восстановления копии роли и PIN сохраняются.


## Контрольный вопрос
У каждого пользователя (администратор и тренеры) свой контрольный вопрос. Задаётся в Настройки → «Вы вошли как» (нужен свой PIN), у администратора также при первом запуске. На экране «Забыли PIN?» верный ответ позволяет задать новый PIN этого пользователя; роль не меняется. Ответ хранится как соленый хеш и нормализуется (регистр, пробелы, знаки, е/ё не важны). Лимит попыток общий с входом: 5 попыток, затем пауза 30 с. Тренер без вопроса обращается к администратору, который задаёт новый PIN в «Пользователи и роли». Администратор может также восстановить доступ по коду восстановления.

## Вход по e-mail
При открытии через сайт и подключённом Supabase локальные PIN не используются: роли выдаёт администратор по адресам электронной почты (`EMAIL-AUTH.md`). Без Supabase действует локальный вход по PIN, описанный выше.
